Open the Spotify Dashboard
You're going to create your own free Spotify Developer app. This is what powers Vinyl Player.

Click the button below to open the Spotify Developer Dashboard in your browser.

Log in with the same Spotify account you use for music. You'll need a Premium account.

Once you're logged in, come back here and click Continue.

add_box
Create a new app
On the dashboard, click Create app and fill in the form.
1
App name — anything you want, e.g. "My Vinyl Player".
2
App description — anything, e.g. "Personal music player".
3
Website — leave this blank.
4
Redirect URI — click Add and paste this exact URL:
http://127.0.0.1:3000/
5
Which API/SDKs — check Web API only.
6
Agree to the terms and click Save.
⚠️ Paste it exactly as shown. Spotify does not allow localhost, only 127.0.0.1.
